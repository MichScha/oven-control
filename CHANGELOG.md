# Changelog

All notable changes to this integration. Versions follow [Semantic Versioning](https://semver.org/);
each version is published as a GitHub release, which HACS offers as an update.

## [0.2.0] - 2026-10-17

### Added

- Polling intervals for the live status (5–300 s) and the settings (1–60 min) under
  *Configure*; the integration reloads when they change.
- Integration icon (light and dark).

### Changed

- Display name is now "Oven Control"; README states that the project is not affiliated with
  the stove or controller makers.

## [0.1.0] - 2026-10-17

### Added

- First version: set-up from the UI with reconfigure, live status, alarms, burn curve,
  relay mode, alarm mask, clock sync and diagnostics.
